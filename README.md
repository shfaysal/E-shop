I’ve been working on E-shop, a native Android application built from the   
  ground up to demonstrate modern development standards, performance, and    
  scalability. This project serves as a comprehensive example of how to build
  a production-ready shopping application using the latest Jetpack libraries.


  ✨ Key Features:
   * Authentication Flow: Secure Login and Registration with JWT token       
     management and persistent sessions.
   * Product Discovery: Browse products with a seamless UI, featuring        
     detailed views and category-based filtering.
   * Cart Management: Dynamic shopping cart with real-time updates and       
     localized state management.
   * Profile & Settings: User profile management including an "Edit Profile" 
     feature and dynamic theme support.
   * Localization: Fully localized with support for multiple languages       
     (English & Bengali).
   * Modern UI/UX: Built entirely with Jetpack Compose and Material 3,       
     featuring custom shimmer effects for loading states and responsive      
     layouts.

  🛠️ Technical Stack & Architecture:
   * Language: 100% Kotlin.
   * UI Framework: Jetpack Compose (Material 3).
   * Architecture: MVVM (Model-View-ViewModel) with a clean-layered approach 
     (UI, Domain, Data).
   * Dependency Injection: Hilt for modular and testable code.
   * Networking: Retrofit + OkHttp for robust API communication.
   * Serialization: Kotlinx Serialization for type-safe data handling.       
   * Navigation: Type-safe Navigation Compose.
   * Local Data: DataStore for secure token and settings storage.
   * Testing: Comprehensive Unit and Instrumented (UI) tests to ensure       
     reliability.

  This project allowed me to dive deep into Type-Safe Navigation and
  Hilt-driven DI, ensuring the codebase remains maintainable as features     
  grow.
